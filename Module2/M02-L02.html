Making Decisions: if & else

Learn how to make your Python programs make smart choices based on simple conditions.

01. What is a Decision in Code?

In real life, you make decisions every day: "If it is raining outside, take an umbrella. Otherwise, wear sunglasses."

In Python, we use the if statement to check if a condition is True. If it is true, Python runs the code inside the if block. 

age = 20

if age >= 18:
    print("You are eligible to vote!")

02. The #1 Beginner Rule: Indentation!

Crucial Python Syntax Rule

Notice the colon (:) at the end of the if line, and the 4 spaces indented on the next line! Python relies on spacing to know which lines belong inside the if statement.

Correct Indentation

if score > 50:
    print("You passed!")

Missing Spaces (Error)

if score > 50:
print("You passed!") ← IndentationError!

03. Adding else for the Backup Path

What happens if the if condition is False? We use else to specify what should run when the condition fails. 

marks = 45

if marks >= 50:
    print("Congratulations, you passed!")
else:
    print("Sorry, you failed. Try again!")
Note: else never takes a condition! It catches everything that isn't caught by if.

Try It Yourself

Write a program with a variable temperature = 32. If temperature is greater than 30, print "It's hot outside!", otherwise print "It's pleasant outside." 

temperature = 32

if temperature > 30:
    print("It's hot outside!")
else:
    print("It's pleasant outside.")
