Python Operators (Comparison & Logical)

Learn how to compare values using operators that return True or False.

01. Comparison Operators

Comparison operators compare two values and answer with either True or False (a Boolean result).

> Greater than
10 > 5 → True
< Less than
3 < 2 → False
>= Greater or Equal
5 >= 5 → True
<= Less or Equal
4 <= 2 → False
== Equal to
5 == 5 → True
!= Not Equal to
10 != 5 → True
Big Beginner Trap: = vs ==

A single = stores a value into a variable (x = 5).
A double == compares two values (x == 5).

02. Logical Operators (and, or, not)

Logical operators let you combine multiple comparison checks together:

and → Returns True ONLY IF both conditions are True.
(10 > 5) and (3 < 8) → True
or → Returns True IF at least one condition is True.
(10 < 5) or (3 < 8) → True
not → Reverses the result (True becomes False).
not(10 > 5) → False

03. Code Example 

age = 20
has_id = True

# Check both conditions using 'and'
can_enter = (age >= 18) and (has_id == True)

print("Can enter event:", can_enter)  # Prints: True

Try It Yourself

Write code with a = 15 and b = 20. Print whether a is equal to b using the == operator. 

a = 15
b = 20

print(a == b)  # Prints: False
