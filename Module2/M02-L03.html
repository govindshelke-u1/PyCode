Multiple Conditions: elif

Learn how to test more than two options using Python's elif (short for "else if").

01. Why Do We Need elif?

An if-else block only handles two outcomes (True or False). But what if you have 3, 4, or more possibilities—like traffic light colors (Red, Yellow, Green) or exam grade tiers (A, B, C, F)?

That's where elif comes in! It allows you to chain multiple conditions together between if and else.

02. How Python Evaluates Conditions

Python checks conditions top to bottom in order:

1.
Checks if first: If it's True, Python runs its code block and skips all the remaining conditions.
2.
Checks elif branches next: If if was False, Python evaluates each elif one by one until it finds a True statement.
3.
Falls back to else: If every if and elif is False, the else block runs as a final backup.

03. Code Example: Traffic Signal System 

signal = "yellow"

if signal == "red":
    print("Stop!")
elif signal == "yellow":
    print("Slow down and prepare to stop.")
elif signal == "green":
    print("Go!")
else:
    print("Invalid signal color!")

# Output: Slow down and prepare to stop.

Try It Yourself

Write a program with score = 85. If score is 90 or above, print "Grade A". If score is 70 or above, print "Grade B" using elif. Otherwise, print "Grade C" using else. 

score = 85

if score >= 90:
    print("Grade A")
elif score >= 70:
    print("Grade B")
else:
    print("Grade C")

# Output: Grade B
