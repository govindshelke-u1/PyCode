Python Tuples & Indexing: ( )

Learn how to store fixed collections of data using round brackets and access items using index numbers.

01. Creating a Tuple

A Tuple is used to store multiple items in a single variable using round brackets ( ) (parentheses). Items are separated by commas. 

# Tuple of strings
fruits = ("apple", "banana", "cherry")

# Tuple of coordinates
coordinates = (10, 20)

# Printing the entire tuple
print(fruits)  # Output: ('apple', 'banana', 'cherry')

02. Accessing Items (Positive Indexing)

Just like lists, every item in a tuple has a position number (index) starting at 0.

fruits[0]
"apple"
fruits[1]
"banana"
fruits[2]
"cherry"
fruits = ("apple", "banana", "cherry")

print(fruits[0])  # Prints: apple
print(fruits[1])  # Prints: banana
print(fruits[2])  # Prints: cherry

03. Accessing Items from the End (Negative Indexing)

You can access items backwards using negative numbers. -1 gets the last item.

fruits[-1]
"cherry" (Last item)
fruits[-2]
"banana" (Second last)
fruits = ("apple", "banana", "cherry")

print(fruits[-1])  # Prints: cherry
print(fruits[-2])  # Prints: banana

04. Lists vs Tuples (The Golden Rule)

List [ ]

Mutable (Changeable): You can add, remove, or modify items anytime after creating a list.

Tuple ( )

Immutable (Unchangeable): Once created, you cannot change, add, or remove items in a tuple.

Try It Yourself

Create a tuple named point containing numbers 100, 200, and 300. Print the first value using point[0] and the last value using point[-1]. 

point = (100, 200, 300)

print(point[0])   # Prints: 100
print(point[-1])  # Prints: 300
