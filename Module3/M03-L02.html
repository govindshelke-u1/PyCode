Python List Methods

Learn how to add, insert, remove, and count items using Python's built-in list methods.

01. Adding Items: append() & insert()

Python gives us two ways to add new items into an existing list:

.append(item)

Adds a new item to the very end of the list.

.insert(index, item)

Inserts a new item at a specific index position, pushing remaining items right. 

fruits = ["apple", "banana"]

# Adds to the end
fruits.append("cherry")
print(fruits)  # ['apple', 'banana', 'cherry']

# Inserts at index 0 (at the beginning)
fruits.insert(0, "mango")
print(fruits)  # ['mango', 'apple', 'banana', 'cherry']

02. Removing Items: remove() & pop()

You can remove items by specifying their value or their index position:

.remove(item_value)

Removes the first occurrence of a specific value from the list.

.pop(index)

Removes (and returns) the item at a specific index. If no index is given, it pops the last item. 

numbers = [10, 20, 30, 40]

# Remove by value
numbers.remove(20)
print(numbers)  # [10, 30, 40]

# Remove by index (index 0 is '10')
numbers.pop(0)
print(numbers)  # [30, 40]

03. List Length: len()

The built-in len() function tells you how many items are currently inside a list. 

colors = ["red", "green", "blue", "yellow"]

total_items = len(colors)
print(total_items)  # Output: 4

Try It Yourself

Create a list items = ["book", "pen"]. Insert "laptop" at index 0, append "mouse" at the end, and then print the list and its total length. 

items = ["book", "pen"]

items.insert(0, "laptop")
items.append("mouse")

print(items)       # ['laptop', 'book', 'pen', 'mouse']
print(len(items))  # Output: 4
