Tuple Operations, Methods & Unpacking

Master built-in tuple methods like count() and index(), and learn how to unpack tuples into variables.

01. Tuple Methods: count() & index()

Because tuples are immutable (uncopyable and unchangeable), they do not have methods like append() or remove(). They only have two built-in methods:

.count(value)

Returns the number of times a specific value appears in the tuple.

.index(value)

Searches for a value and returns its first index position. 

numbers = (10, 20, 20, 30, 20)

# Count how many times 20 appears
print(numbers.count(20))  # Output: 3

# Find the first index position of 30
print(numbers.index(30))  # Output: 3

02. Getting Tuple Length with len()

Just like with lists, you can use the built-in len() function to determine how many items are stored inside a tuple. 

user_info = ("Alex", 24, "Developer")

print(len(user_info))  # Output: 3

03. Tuple Unpacking

Unpacking allows you to extract items from a tuple directly into individual variables in a single line of code.

Unpacking Rule

The number of variables on the left side must exactly match the number of items inside the tuple on the right side! 

# Tuple with 3 coordinates
point = (10, 20, 30)

# Unpacking into 3 variables
x, y, z = point

print(x)  # Output: 10
print(y)  # Output: 20
print(z)  # Output: 30

Try It Yourself

Create a tuple rgb = (255, 128, 0). Unpack it into three variables r, g, and b, and print g. Also use .count(255) to check how many times 255 appears in rgb. 

rgb = (255, 128, 0)

# Unpack variables
r, g, b = rgb
print(g)  # Output: 128

# Count occurrences
print(rgb.count(255))  # Output: 1
