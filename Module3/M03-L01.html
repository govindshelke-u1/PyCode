Python Lists & Indexing: [ ]

Learn how to create a list and access any item inside it using index numbers.

01. Creating a List

A List allows you to store multiple items in a single variable using square brackets [ ]. Items inside a list are separated by commas. 

# List of strings
fruits = ["apple", "banana", "cherry"]

# List of numbers
marks = [85, 92, 78]

# Printing the entire list
print(fruits)  # Output: ['apple', 'banana', 'cherry']

02. Accessing Items (Positive Indexing)

Every item in a list has a position number called an index. In Python, counting starts at 0!

fruits[0]
"apple"
fruits[1]
"banana"
fruits[2]
"cherry"
fruits = ["apple", "banana", "cherry"]

print(fruits[0])  # Prints: apple
print(fruits[1])  # Prints: banana
print(fruits[2])  # Prints: cherry

03. Accessing Items from the End (Negative Indexing)

You can also count backwards from the end of a list using negative numbers! -1 always points to the last item.

fruits[-1]
"cherry" (Last item)
fruits[-2]
"banana" (Second last)
fruits = ["apple", "banana", "cherry"]

print(fruits[-1])  # Prints: cherry
print(fruits[-2])  # Prints: banana

Try It Yourself

Create a list named cities containing "Mumbai", "Delhi", and "Pune". Print the first city using positive index [0] and the last city using negative index [-1]. 

cities = ["Mumbai", "Delhi", "Pune"]

print(cities[0])   # Prints: Mumbai
print(cities[-1])  # Prints: Pune
