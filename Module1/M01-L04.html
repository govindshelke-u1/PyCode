Taking User Input with input()

Make your programs interactive by asking users for information and using their answers in your code.

01. How Does input() Work?

The input() function pauses your program and waits for the user to type something into the terminal and press Enter. 

# Ask the user for their name and store it in a variable
name = input("Enter your name: ")

print("Welcome,", name)

02. The #1 Trap: input() ALWAYS Gives Text!

Crucial Rule

No matter what the user types (even if they type numbers like 25), input() always gives you a Text String (str).

Direct Addition Fails

age = input("Age: ") # "20"
age + 1 → TypeError!

Python cannot add a number to text ("20" + 1).

Convert with int() First

age = int(input("Age: "))
age + 1 → 21 (Success)

Convert to integer before doing math.

03. Combining input() and Conversion

Here is how you ask for numbers and perform math correctly: 

# Simple Calculator Example
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

sum_result = num1 + num2
print("Total Sum is:", sum_result)
