Your First Program: Hello, World!

Write your very first line of Python code and understand how the print() function works.

01. The print() Function

In Python, print() is an instruction that tells the computer to display whatever is inside the parentheses onto your screen. 

# Your first Python code!
print("Hello, World!")
>>> Terminal Output:
Hello, World!

02. Why Do We Use Quotes " "?

Notice that "Hello, World!" is enclosed in double quotes. The quotes tell Python: "Treat this as raw text, not code commands."

With Quotes

print("Hello")
Python prints the exact text Hello to your screen.

Without Quotes

print(Hello)
Python thinks Hello is a variable command and throws a NameError.

03. 3 Common Beginner Mistakes

1.
Capitalizing Print: Print("Hello")
Python is case-sensitive. Always use lowercase print.
2.
Forgetting Parentheses: print "Hello"
In Python 3, parentheses () are mandatory.
3.
Mismatched Quotes: print("Hello')
Start and end with the same quote type (" " or ' ').
