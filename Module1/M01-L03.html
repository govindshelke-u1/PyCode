Data Types & Type Casting

Master Python's core data types, inspect types with type(), and convert values easily.

01. Checking Types with type()

Python automatically knows what kind of data you store in a variable. You can check any variable's data type using type(). 

x = 10         # int (Whole Number)
y = 3.14       # float (Decimal Number)
z = "Hello"    # str (Text)
is_valid = True # bool (True/False)

print(type(x))  # Outputs: <class 'int'>
print(type(z))  # Outputs: <class 'str'>

02. Numbers in Quotes: "10" + "5"

Any number inside quotes is treated as plain text, not math numbers!

Text Joining (Quotes)

"10" + "5" = "105"

Python glues text together side-by-side.

Math Addition (No Quotes)

10 + 5 = 15

Unquoted numbers do actual math.

03. Type Casting (Converting Values)

You can convert a value from one data type to another using these built-in helpers:

int("10") → Converts text string to whole number
10
float("5.5") → Converts text string to decimal number
5.5
str(100) → Converts number to text string
"100" 
# Converting text number into an integer to do math
price_text = "50"
price_number = int(price_text)

total = price_number + 10
print(total)  # Outputs: 60

Try It Yourself

Create a text variable a = "20", convert it to an integer, multiply it by 3, and print the result. 

a = "20"
num = int(a)
result = num * 3

print(result)  # Prints: 60
